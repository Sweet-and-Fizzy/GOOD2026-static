Supporting Interactive Graphical Applications with Open OnDemand, on Premise and in Azure

This BoF brings together users and resource providers that are interested in running interactive graphical applications in Open OnDemand. This can be web applications like Jupyter Notebooks or desktop applications like RStudio, Matlab or Visual Studio Code.
