KROOD: Kubernetes Running Open OnDemand
Aaron Janssen [North Dakota State University]

Kubernetes has emerged as a de facto standard for deploying distributed systems and complex, multi-service web applications, and is gaining popularity in HPC environments. Given its demonstrated utility for research computing, how can we leverage Kubernetes for orchestrating Open OnDemand (OOD) deployments? In this talk, we present a Kubernetes operator we developed for deploying and managing OOD inside a Kubernetes cluster. We demonstrate how our operator can be used with a pilot implementation of a Kubernetes-native OOD architecture that allows for network available PUNs and advanced scheduling. Finally, we’ll close with a discussion of the pros, cons, and potential use cases for the KROOD approach to OOD management.
