An Intuitive, Extensible Open OnDemand Dashboard for Job Accounting and Performance Metrics
Richie Tan [Purdue]

High-performance computing allows researchers across the globe to conduct research at scale. At Purdue University, Open OnDemand provides an easy way for users to access cluster resources and launch popular applications with minimal barriers. In order to improve how users interact with clusters, we are building a user-friendly, modular web dashboard on Open OnDemand with detailed, organized cluster information and color-coded visualizations. By combining Slurm-based data sources and modular widgets and components, this dashboard allows researchers to access cluster information about their jobs and allocations easily and provides a modular, extensible framework to install on any Slurm-based cluster.
